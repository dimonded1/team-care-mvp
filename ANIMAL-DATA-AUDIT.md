# Каталог подопечных из Bitrix

Дата контрольной синхронизации: 2026-07-28

## Текущий источник

Ручной демонстрационный каталог и его локальные фотографии удалены. Приложение
использует проверенный статический снимок из двух воронок Bitrix:

- `Мокрый Нос` — категория сделок `17`;
- `Малино` — категория сделок `13`.

Снимок создаётся серверным скриптом `npm run sync:animals`. Вебхук читается
только из локального `.env`; в браузер, JSON-снимок и логи он не попадает.

## Какие поля перенесены

Из Bitrix в публичный снимок входят:

- стабильный CRM ID и воронка;
- кличка;
- вид и пол из перечислений;
- дата рождения; отображаемый возраст вычисляется в приложении и не устаревает;
- короткий фрагмент публичного описания;
- локально сохранённое основное фото;
- отметки о наличии исходного описания, характера, поведения и галереи.

Главные фотографии скачиваются через временный `urlMachine` из `crm.item.get`.
Ссылка проверяется по HTTPS и домену Bitrix, ответ ограничен по размеру и
проверяется по MIME и сигнатуре файла. Подписанная ссылка после скачивания не
сохраняется. Изображения уменьшаются до 1600 px на macOS, поэтому текущий набор
весит около 1,8 МБ вместо исходных 27 МБ.

## Что не удалось перенести напрямую

- Поле отдельной публичной ссылки на карточку пусто у всех шести записей.
  Интерфейс использует общий каталог `https://fond-nika.ru/ourpets/`.
- Отдельное поле «история» пусто; текст взят из заполненного публичного
  описания/комментария и ограничен первыми тремя предложениями.
- В Bitrix нет семи числовых осей мэтчинга, тегов заботы, короткой подписи и
  родительного падежа клички. Они находятся в отдельном проверяемом редакционном
  слое `src/data/animalEditorial.ts`, чтобы их нельзя было спутать с CRM-данными.
- Дополнительные фотографии учитываются в отчёте полноты, но в первую тестовую
  версию переносится только основная фотография.

## Обновление

1. На сервере заполнить `.env`; обязательные воронки перечислить как
   `BITRIX_ANIMAL_CATEGORY_IDS=17,13`.
2. Оставить исходящие feature flags выключенными: синхронизация животных
   временно включает только read-only контур внутри процесса.
3. Запустить `npm run sync:animals`.
4. Проверить `npm test`, `npm run test:server` и `npm run build`.

Скрипт прервётся до записи снимка, если карточка стала неопубликованной,
заблокирована, перенесена в другую воронку, лишилась обязательных полей или
фотография не прошла проверку.
